Video Game Forecasting

Python • Pandas • Matplotlib • SciPy • Statistical Analysis

Forecasting analysis project evaluating historical video game sales to identify the platform, genre, review, and regional factors that influenced performance and supported 2017 marketing recommendations.

EDA Hypothesis Testing Forecasting Regional Analysis
