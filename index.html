Neural Networks & Regression

Medical Insurance Cost Prediction

Neural network regression project predicting individual medical insurance charges from demographic and health-related features using a regularized TensorFlow/Keras model.

Tools Used

Python Pandas Scikit-learn TensorFlow Keras Neural Networks

Highlights

  • Cleaned a 1,338-record medical insurance dataset, removed one duplicate, and prepared 11 model inputs using standardized numeric features and one-hot encoded categorical variables.
  • Built a neural network with 64, 32, and 16-neuron hidden layers using ReLU activation, batch normalization, 30% dropout, and L2 regularization.
  • Used early stopping, model checkpointing, and learning-rate reduction to preserve the strongest validation model and reduce overfitting.
  • Achieved a test MAE of $2,168.14, RMSE of $3,798.14, and R² of 0.8873, explaining approximately 88.73% of the variation in unseen insurance charges.

Machine Learning & Churn Prediction

Beta Bank Customer Churn Prediction

Machine learning classification project predicting customer churn to help a bank identify customers at risk of leaving and support targeted retention decisions.

Tools Used

Python Pandas Scikit-learn Machine Learning Classification Model Evaluation

Highlights

  • Cleaned and prepared a 10,000-record customer dataset by removing identifiers, imputing missing values, encoding categories, and scaling features.
  • Analyzed class imbalance and found that 20.4% of training customers exited, then tested class weighting and upsampling to improve churn detection.
  • Compared Logistic Regression, Decision Tree, and Random Forest models to identify the strongest churn prediction approach.
  • Evaluated the final Random Forest model on the test set, achieving an F1 score of 0.5988 and AUC-ROC of 0.8556.
